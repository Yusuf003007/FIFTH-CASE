# Setup dev environment

## Setup unity
1. Download `unity hub` from the [offical website](https://unity.com/download)
2. You will need to create an account and then connect
3. After that, on unity hub, install the `Unity 6.3 LTS`
  <img width="1182" height="301" alt="image" src="https://github.com/user-attachments/assets/78c10dfa-1e04-4e93-b287-78f9d5f27939" />

## Setup git and github app
### Install git
If you have already git, you skip this step
1. Download ([windows](https://github.com/git-for-windows/git/releases/tag/v2.53.0.windows.2) [mac](https://git-scm.com/install/mac) and install it

## Install github app (help to visualize more easily)
1. Donwload [github app](https://desktop.github.com/download/), install it
2. It will ask to connect to your github account

## Setup the repo on you local machine
1. Go on the github app, on the left panel, click on add -> clone repository
   <img width="476" height="296" alt="image" src="https://github.com/user-attachments/assets/d23c1cc8-ab6e-4efa-8e8a-df315c458e55" />
3. Search for out project `FIFTH-CASE`
4. Choose a folder where you want the project directory to be
5. Then clone it
  <img width="510" height="461" alt="image" src="https://github.com/user-attachments/assets/3e5a2719-87fa-4139-b878-e4d03d1f1891" />

Now you successfully set up your dev environment.
